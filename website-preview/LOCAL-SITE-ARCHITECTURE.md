# Arborwise Local Site Architecture

## Purpose

Build a strong main Arborwise website first, then create local entry points that help homeowners in each priority city find information that actually applies to them and move naturally back to Arborwise.

## Main site

Primary authority and conversion site:

- arborwisetreecare.com
- Arborwise brand, team, services, reviews, concern checker, educational resources, property-management experience, and estimate/contact actions
- All local pages and any campaign domains ultimately support this site

## Priority local pages

Provisional first group:

- /anna-tree-service/
- /van-alstyne-tree-service/
- /howe-tree-service/
- /princeton-tree-service/

Confirm the fourth city before publication if “Princeton” was not the intended name.

## What makes each local page genuinely useful

Each page must contain local, original evidence rather than copied city-name substitutions:

- Arborwise jobs and photos from that city or nearby service area
- Common local tree species and visible problems
- Soil, drainage, wind, drought, storm, development, and construction concerns relevant to the area
- Local pruning, removal, risk, and storm-response examples
- A city-specific review, project story, or property-management example when available
- Clear service-area statement and realistic response expectations
- City-specific title, description, headings, internal links, FAQs, and structured data
- Direct call, text-photo, email, and estimate actions

## Independent domains

Optional city domains can be purchased for brand protection or advertising, but they should normally redirect to the matching Arborwise location page.

Do not publish thin duplicate mini-sites that merely swap city names and point to the same main page. If a true standalone local site is ever used, it must be a distinct local resource with substantial original content, its own useful navigation, and a clear Arborwise relationship.

## Google Business Profile

Do not create separate city profiles unless Arborwise has a legitimate staffed location that independently qualifies. Service-area coverage belongs under the legitimate Arborwise profile and website location pages.

## Build order

1. Lock the main Arborwise design, voice, assets, mobile experience, and conversion flow.
2. Build the local-page template around real evidence, not filler.
3. Complete Anna and Van Alstyne first because Arborwise has the strongest current community recognition there.
4. Complete Howe and Princeton after gathering local photos, jobs, reviews, and useful city-specific facts.
5. Add optional redirect domains only after the corresponding local page is complete.
6. Measure calls, texts, estimate starts, engagement, and search performance by local page.
